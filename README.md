# Sleiv

Ukemeny og middagsplan for iPhone.

Legg inn middagene du lager ofte, planlegg uken og se dagens middag i en
widget på hjemskjermen. Alt lagres på telefonen din.

- [Nettside](https://kristofferchr.github.io/sleiv/)
- [Personvernerklæring](https://kristofferchr.github.io/sleiv/privacy/)
